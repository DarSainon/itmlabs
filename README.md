# itmorev.ru — статическая версия для GitHub Pages

## 🚀 Как развернуть (5 минут, бесплатно)

### Шаг 1: Регистрация на GitHub
1. Открой [github.com](https://github.com)
2. Нажми **Sign up** (зарегистрироваться)
3. Введи логин, email, пароль
4. После входа: нажми на аватарку в правом верхнем углу → **Settings** → **Language** → выбери **Русский**

### Шаг 2: Создание репозитория
1. Нажми зелёную кнопку **«Новый»** (New repository)
2. В поле **Repository name** введи: `itmorev.ru`
3. Поставь галочку **Public** (публичный)
4. Нажми **«Создать репозиторий»**

### Шаг 3: Загрузка файлов
1. На странице репозитория нажми **«добавление файла»** → **«Загрузить файлы»**
2. Перетащи **все** файлы из этого архива (index.html, папки css/, js/, lab/, science/, dnd/, blog/, ai-experiments/, cyss/)
3. В поле «Описание коммита» напиши: `Первая версия сайта`
4. Нажми **«Зафиксировать изменения»** (Commit changes)

### Шаг 4: Включение GitHub Pages
1. Перейди в **Settings** (настройки репозитория)
2. Слева выбери **Pages**
3. В разделе **Source** выбери **Deploy from a branch**
4. Ветка: `main`, папка: `/(root)`
5. Нажми **Save**
6. Подожди 1 минуту — появится ссылка: `https://твой-логин.github.io/itmorev.ru/`

### Готово!
Открой ссылку — сайт работает. Все разделы уже готовы:
- `/lab/` — живой редактор кода
- `/science/` — научные проекты (с примером симуляции волн)
- `/dnd/` — заготовка сайта для D&D-кампании
- `/blog/` — блог с первой статьёй
- `/ai-experiments/` — AI-эксперименты
- `/cyss/` — тестирование проектов для Совета молодых учёных

## ✏️ Как добавлять новые страницы

1. На GitHub зайди в нужную папку
2. Нажми **«Добавить файл»** → **«Создать новый файл»**
3. Напиши код HTML и сохрани
4. Через минуту страница появится на сайте

Или создай новую папку (например, `наука/новый-проект/`) и загрузи туда `index.html`.
